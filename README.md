# mellow-lantern-cli

Mobile developer · React Native and Expo

拿来练手的小仓库

## 用法

```bash
cat data.txt | go run main.go
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

```bash
cd mellow-lantern-cli
go build ./...
```
